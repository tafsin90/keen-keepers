# Keen Keeper

A personal relationship tracker built with Next.js that help me keep important friends and contacts organized, visible, and easy to follow up with.

## Technologies Used

- Next.js 16
- React 19
- Tailwind CSS 4
- DaisyUI
- React Icons
- React Toastify
- Recharts

## Key Features

1. **Friend activity dashboard** — view total friends and active/inactive/overdue status counts at a glance.
2. **Interactive friends list** — browse contacts with profile images, tags, last contact age, and status badges.
3. **Detail-driven relationship tracking** — navigate to individual friend pages to manage meaningful connection information.

## Project Structure

- `src/app/` — main application pages and routing
- `src/components/` — reusable UI components
- `src/utils/` — helper logic for status, timeline, and toast behavior
- `public/friends.json` — sample friends data used by the app

## Run Locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000` in your browser.
